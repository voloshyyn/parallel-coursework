# Перевірка повної курсової роботи

Дата: 23.11.2026. Актуальні вихідні тексти; Linux у Docker Desktop.
Машинозчитуваний протокол та живий LLM trace: `bench/results/verification.json`.

## Автоматичні перевірки

- Документований `docker build --target test`: 134/134 CTest, 9,28 с.
- ThreadSanitizer на актуальних джерелах: 134/134, 13,78 с; runtime-повідомлень
  про гонки немає. GCC попереджає про обмеження atomic_thread_fence у сторонній
  Asio. Відсутність повідомлень не доводить відсутність усіх можливих гонок.
- Node UI suite: 16/16; генератор: 7/7; C++ CLI: 6 сценаріїв через HTTP fixture;
  підготовка моделі: 3 сценарії (pull, кеш, помилка).
- clang-format Google: перевірка всіх .cpp/.h у src і tests без зауважень.
- git diff --check без зауважень.
- Повні CTest/TSan runtime-логи: `bench/results/ctest.log`, `tsan.log`.

## Стандартний Compose та реальна модель

Без окремого профілю запускаються server, ollama і model-init. Модель
qwen2.5:1.5b вже була в томі; model-init автоматично використав кеш і прогрів
модель, завершився з кодом 0. Перший pull перевірений HTTP fixture; повторне
завантаження реальних ваг з мережі у цьому прогоні не виконувалося.

На новому порожньому томі даних HTTP відповів через 2,283 с від запуску Compose,
поки корпус ще готувався. Пошук по 12 000 документах став готовим через
143,241 с; автоматична індексація чотирма потоками тривала 7,120 с.
Це контроль старту, не точка експерименту масштабованості.

Full містить 12 000 .txt і 2 462 028 386 байтів. Повторний запуск генератора
з --verify-hash підтвердив SHA-256 та повторне використання. Датасет не скачувався.
При навмисно неправильному профілі /api/ready показав startup_state=error,
startup_error та search_ready=false; HTTP лишався доступним. Контейнер завершився
по SIGTERM з кодом 143, без примусового SIGKILL.

## Живі клієнти

- REST/CLI `search --json "coral reef"`: 10 результатів з doc_id, score, snippet.
- WebSocket: реальна модель додала ecosystem, marine, biodiversity; порядок
  query_expansion → keyword_search → done, 10 результатів; близько 650 мс
  end-to-end у контрольному прогрітому запиті.
- Chromium: усі три етапи готові, 10 результатів; поле й кнопка знову доступні;
  0 помилок та 0 попереджень JavaScript-консолі.
- Вебресурси локальні, жодного CDN для Vue не потрібно.
